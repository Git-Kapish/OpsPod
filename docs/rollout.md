## Promotion criteria

| From -> to | Must hold for 7 consecutive days |
|---|---|
| Shadow -> Assisted | agreement on outcome+route >= 95%; 0 `PolicyViolationBlocked` alerts; 0 pipeline crashes; every disagreement reviewed |
| Assisted -> Canary | approver override rate < 5%; approval wait p95 within SLA; reversal rate < 1%; no unresolved dead letters |
| Canary (25%) -> Auto | canary reversal rate no worse than the assisted baseline; no unauthorized-action incidents; auto-resolve rate on target |
| Any -> lower | any page-severity alert, `PolicyViolationBlocked > 0`, or reversal spike: set the mode back one stage (or `KILL_SWITCH`) first, investigate second |

Override rate and reversal rate need real humans and cannot be measured here; they are exit criteria to be measured in production.

## Controls available at every stage

- Mode and canary percentage: `PUT /v1/admin/flags` (per region and case type overrides supported).
- Kill switch: `PUT /v1/admin/flags {"kill_switch": true}` routes everything to humans and disables LLM calls immediately, mid-case included.
- Reversal: `POST /v1/actions/{id}/reverse` creates a compensating ledger entry.
